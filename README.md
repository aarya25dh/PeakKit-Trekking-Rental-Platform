# PeakKit 🏔️

> Explore More. Carry Less.

PeakKit is a digital outdoor adventure platform that helps trekkers rent, reserve, buy, and sell verified outdoor gear in Nepal.

## Features (Version 1)

- Gear Rentals
- Adventure Kits
- Gear Advisor
- Used Gear Marketplace
- Reservations
- Wishlist
- Reviews
- Security Deposits
- Inventory Management
- Admin Dashboard

## Tech Stack

### Frontend
- React.js (Vite)
- Tailwind CSS
- DaisyUI
- Framer Motion

### Backend
- Django
- Django REST Framework

### Database
- PostgreSQL

Developed as a Semester VI E-Commerce Project (BSc. CSIT).
